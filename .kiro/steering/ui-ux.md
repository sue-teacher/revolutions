# 지수쌤과 혁명 탐험대 — 디자인 시스템

이 프로젝트의 UI는 [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
방법론을 참고해 "일관된 디자인 시스템"을 세우는 방식으로 다듬는다.
(스킬 내용은 라이선스 준수를 위해 재구성해 정리했다.)

## 1. 디자인 패턴
- 대상: 중학교 2학년 역사 복습 **학습형 게임** 웹앱
- 스타일 키워드: 밝고 또렷한 교육용 게임, 부드러운 깊이감(soft depth), 둥근 모서리, 명확한 위계
- 핵심 화면: 홈(지도+스테이지) → 학습 → 퀴즈 → 결과 / 보조: 매칭 게임, 틀린 문제 다시보기

## 2. 색 토큰 (CSS 변수)
- 배경은 짙은 남색 계열의 그라데이션으로 "모험 지도" 분위기
- 표면(surface)은 명도 단계를 둬서 깊이 표현: `--surface-1 ~ --surface-3`
- 포인트색(accent)은 금색, 긍정은 민트, 경고는 산호색으로 역할 고정
- 색은 반드시 토큰(변수)으로만 사용. 하드코딩 색상 추가 금지

## 3. 타이포그래피
- 한글 본문: Pretendard (Google Fonts의 Gowun/Noto 대체 가능)
- 제목 강조: 두껍고 큰 크기 + 음수 자간
- 타입 스케일: 2rem+ (타이틀) / 1.25rem (문항) / 1rem (본문) / 0.85rem (보조)

## 4. 간격 · 반경 · 그림자
- 간격 스케일(4px 기반): `--space-1=4, 2=8, 3=12, 4=16, 5=24, 6=32`
- 모서리 반경: 카드 `--radius`, 버튼은 pill(999px)
- 그림자: 1단계(은은), 2단계(카드), 포커스 링은 accent로 또렷하게

## 5. 상호작용 · 접근성
- 버튼은 눌림(active) 피드백, hover 시 살짝 떠오름(translateY)
- 포커스는 `:focus-visible`로 또렷한 링 제공
- 터치 타깃 최소 44px, 본문 대비 충분히 확보
- 애니메이션은 짧고(≤0.4s) 과하지 않게. `prefers-reduced-motion` 존중

## 6. 규칙
- 새 컴포넌트는 위 토큰을 재사용하고 임의 값(매직 넘버) 사용을 피한다
- 색/간격/그림자를 바꿔야 하면 토큰 정의부터 수정한다
